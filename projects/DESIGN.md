# 赛博派蒙·旅游搭子 - 设计规范

## 产品定位
- **核心人格**：AI旅游搭子「阿穗」（模拟派蒙的陪伴感）
- **产品调性**：游戏化、沉浸感、温暖陪伴、探索趣味
- **目标用户**：喜欢原神式探索体验的年轻用户、广州深度游爱好者

## 设计风格选择
**风格：自然有机风 + 游戏化元素**
- 融合「开放世界探索」的游戏感
- 使用温暖的大地色系配合广州特色元素
- 卡片采用有机不规则圆角
- 适度融入游戏成就/等级系统视觉语言

## 色彩系统

### 主色调
- **Primary**: `#2D7D46` (森林绿 - 代表探索、自然)
- **Secondary**: `#D4A574` (沙金色 - 代表阳光、广州地标)
- **Accent**: `#E85D4C` (朱红 - 代表活力、打卡成就感)
- **Background**: `#FDF8F2` (暖白 - 温馨友好)
- **Surface**: `#FFFFFF` (纯白卡片)
- **Text Primary**: `#1A1A1A`
- **Text Secondary**: `#666666`
- **Muted**: `#999999`

### 区域色彩（7大区域）
- 越秀（五羊圣地）: `#8B4513` 赭石色
- 荔湾（西关风华）: `#DAA520` 金色
- 海珠（珠水映城）: `#4682B4` 蓝色
- 天河（都市新核）: `#9370DB` 紫色
- 番禺（古邑新章）: `#228B22` 翠绿
- 白云（云山叠翠）: `#87CEEB` 天蓝
- 黄埔（海丝古港）: `#CD853F` 棕色

## 导航结构

### 底部Tab Bar (5个)
1. **首页** - 阿穗对话 + 今日任务 + 快捷打卡
2. **地图** - 广州大世界地图探索
3. **任务** - 主线/支线任务追踪
4. **日历** - 回忆日历打卡历史
5. **我的** - 成就收集 + 足迹统计 + 设置

## 页面布局要点

### 首页
- 顶部：阿穗形象展示区（角色立绘+状态）
- 中部：对话气泡区（可滚动查看历史消息）
- 底部：快捷操作栏（打卡、拍照、语音输入）

### 地图页
- 全屏手绘风格地图
- 顶部：区域切换Tab
- 地图：锚点图标 + 迷雾遮罩
- 底部：当前任务提示悬浮卡

### 任务页
- 主线进度条置顶
- 支线任务卡片列表
- 状态标签（进行中/已完成/未解锁）

### 日历页
- 月视图日历主体
- 打卡天数标记
- 底部选中日详情预览

### 我的页
- 用户信息卡片
- 成就墙（网格展示）
- 足迹统计（数字大卡片）
- 设置入口列表

## 组件规范

### 打卡卡片
- 圆角: 20px
- 阴影: 0 4px 12px rgba(45,125,70,0.1)
- 内边距: 16px
- 图片圆角: 12px

### 成就徽章
- 圆形图标容器
- 未解锁：灰色遮罩 + 锁图标
- 已解锁：金色边框 + 发光效果

### 任务卡片
- 左侧：任务类型图标（主线蓝色/支线橙色）
- 中部：任务标题 + 描述
- 右侧：状态进度或奖励图标

## 动效设计
- 打卡成功：Lottie庆祝动画 + 粒子效果
- 区域解锁：迷雾消散动画
- 成就获得：弹窗 + 震动反馈
- 页面切换：平滑滑动过渡
